## ♻️ ReUse!

O **ReUse!** é uma plataforma com o objetivo de incentivar práticas sustentáveis por meio da reutilização de itens. A proposta do projeto é conectar pessoas que desejam descartar objetos em bom estado com outras que podem reutilizá-los, promovendo consumo consciente, redução de desperdício e impacto positivo no meio ambiente.

Projeto acadêmico em desenvolvimento por Evelin Julia Hashimoto Silva e Rebecca Dias Martins | FIAP.

---

## ⚙️ Como executar o projeto

Para rodar o projeto localmente, siga os passos abaixo:

```bash
# Clone o repositório
git clone <https://github.com/evehashimoto/website-ReUse.git>

# Acesse a pasta do projeto
cd reuse

# Instale as dependências
npm install

# Execute o projeto no terminal
npm run dev
```

Após isso, abra o navegador e acesse:

```
http://localhost:1880/ui
```
